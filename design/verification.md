# 設計與驗證紀錄

## 參考與實作

設計參考：`concept.png`（內建 Image Gen，1536 × 1024）。最終畫面：`game-desktop.png`（Codex 內建瀏覽器原生截图）。兩者均已使用 `view_image` 實際檢視。

依照參考的微縮城市方向，比對了下列項目：

| 項目 | 實作與比對結果 |
| --- | --- |
| 主畫面結構 | 保留頂部品牌列、左側大型棋盤、右側玩家／回合／紀錄。 |
| 色彩 | 保留象牙白、森林綠、薄荷色地面、彩色地產。調低場景曝光並讓地產標籤不受色調映射影響。 |
| 字型與層次 | 繁體中文無襯線字型，現金數字、回合、主要按鈕各有清楚層級。加大地產紋理文字。 |
| 角色與場景 | 真正 3D 建築、樹木、噴泉、四色人物棋子與升級房屋，可全方位水平旋轉及調整俯仰。 |
| 空間與容器 | 開放式棋盤、單一右側操作區、底部相機工具列；較矮桌面改為側欄獨立捲動。 |
| 小螢幕 | 390 × 844 檢查通過，棋盤在上、玩家及回合操作在下；DOM 寬度 375，scrollWidth 375，無水平溢出。 |
| 互動 | 擲骰後逐格移動，當前玩家與落點標示、地產購買、電腦回合、重新整理續玩皆有實測。 |

原尺寸 1536 × 1024 已於瀏覽器 viewport 驗證，另檢查一般 1280 × 720 及手機尺寸。IAB 完整頁面截图在 viewport override 下出現縮放拼接問題，改存原生可見畫面截图；最終截图採已還原的預設桌面尺寸。

## 刻意調整

實作忠於參考的版面方向與微縮城市風格，但並非逐像素重製。為满足可任意旋轉的需求，概念圖中的靜態城市被實際 3D 幾何模型取代，建築數量與街道細節較簡潔。原圖為示意地名及價格，實作改成一致的 32 格、自訂快速遊戲規則，房價與租金均由規則引擎計算。

首屏文案比對：保留「城市大亨」「CITY TYCOON」「玩一場，擁有一座城。」「遊戲規則」「新遊戲」「你的回合」「擲骰子」。將「最新事件」改成「城市動態」；增加操作必需的「我的地產」、存檔狀態及 40 輪上限。初始事件為真實歡迎紀錄，不填入尚未發生的假購地或收租。

## 功能驗證

- 瀏覽器實際擲出 2 + 3，移動至民生東路，花 $1,400 購買，現金從 $15,000 變成 $13,600。
- 地產手冊顯示租金 $252、每級建造費 $840，未集齊同色時升級鈕停用。
- 艾米停在民生東路，支付 $252，玩家現金變成 $13,852；三位電腦完成回合後正確回到玩家第 2 輪。
- 手機實際擲骰、捲動操作；桌面拖曳旋轉、俯視、放大、重置與直接點選南京東路均成功。
- 在購地決策時重新整理，保留目前地產、現金、位置及決策狀態。
- 規則彈窗、Escape 關閉、新遊戲確認及重設成功。交付時已回到全新初始對局。
- 瀏覽器沒有 console error。移除 Three.js Clock 與 PCFSoftShadowMap 的過時 API 使用。
- `npm test`：10 項通過，其中含 100 場完整對局模擬；覆蓋租金、同色加成、升級、稅收、資產變賣、破產、監獄、事件與 40 輪結算。
- `npm run build`：通過。Three.js 所在 JS bundle 約 779 kB（gzip 213 kB）；Vite 有套件體積提示，非建置錯誤。

## 圖像生成紀錄

使用內建 Image Gen，非 API/CLI。概念提示包含：完整繁體中文 3D 城市地產桌遊畫面、象牙白／森林綠、左側 32 格微縮城市棋盤、右側四玩家與雙骰操作、相機工具列，場景需能以真實 3D 幾何實作。

生產插畫提示包含：低多邊形玩具城市、薄荷綠建築、珊瑚色小屋、樹木、金幣與黄色機會信封、溫暖象牙白背景、無文字無邊框，3:2 構圖。輸出保存為 `../public/chance.png`，用於新遊戲與機會事件畫面。
