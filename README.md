## 啟動

已安裝依賴後，雙擊 `start-game.cmd`，再開啟 http://127.0.0.1:5173 。或在專案目錄執行：

```sh
npm install
npm run dev
```

需要 Node.js 20.19+ 或 22.12+、支援 WebGL 2 的現代瀏覽器。首次安裝需要網路；3D 模型由程式生成，無遠端模型依賴。Google Fonts 無法連線時會使用系統中文字型。

## 操作

- 滑鼠左鍵拖曳：360° 水平旋轉及調整俯仰。右鍵拖曳：平移。
- 滾輪或右下方放大、縮小按鈕：調整距離。
- 觸控：單指旋轉、雙指縮放與平移。
- 工具列提供自動旋轉、重置、俯視。
- 點擊棋盤地產或「我的地產」：查看地價、租金、擁有者與建造條件。
- 擲骰後逐格移動；可購買無主地產、跳過購買、走到自己的土地時建造或變賣地產，再結束回合。
- 擲骰前可選擇 1 顆或 2 顆骰子，按點數總和前進；擲骰後不能更改。每位玩家的選擇會隨進度儲存，預設與電腦玩家使用 2 顆。
- 遊戲中可從上方「技能卡圖鑑」查詢所有技能卡的完整說明；持有技能卡時，點擊手牌即可查看效果並依提示使用。

## 手動儲存與讀取

- 點擊棋盤下方的「儲存／讀取」開啟存檔管理；開啟管理畫面時遊戲會暫停，電腦對手與移動動畫不會繼續執行。
- 輸入存檔名稱後按「儲存目前進度」。名稱留白時會使用目前回合作為名稱。
- 手動存檔最多保留 10 個版本。第 11 次儲存時，系統會提示是否刪除最舊版本後保存新的進度。
- 每份手動存檔自建立時間起保留 30 天，讀取存檔不會延長期限；過期存檔會在開啟遊戲或存檔管理時自動清除。
- 儲存與讀取包含目前回合、玩家資金、地產、骰子、移動剩餘步數及事件狀態，因此可以在棋子移動途中保存並接續遊戲。
- 讀取前會要求確認，讀取後會取代目前尚未手動保存的遊戲進度；讀取成功後也會更新目前的自動存檔。
- 手動存檔與自動存檔分開管理。新遊戲只會重設目前對局，不會刪除手動存檔。
- 存檔使用目前網站的瀏覽器 `localStorage`，只在相同網址與相同瀏覽器中可用；清除網站資料會一併刪除自動及手動存檔。

## 自訂快速規則

- 每位玩家起始現金為 $15,000；每次經過起點領取 $2,000。
- 新遊戲可設定初始通膨率（0%–5%，預設 1%）；每完成一輪，物價指數依當前通膨率複利調整，最高為 10×。機會／城市基金可能使通膨率升降 1 個百分點，最低 0%、最高 10%；降低通膨率不會造成物價下跌。
- 地價、租金、建造費、稅金、起點獎勵、事件金額、變賣收入與終局地產估值都依目前物價指數換算。玩家現金餘額不會自動改變；舊存檔載入時採 0% 通膨與 1× 物價指數。
- 不需要集齊同色地產：只要走到自己的土地，就能在該次落地決定是否建造。
- 每次落地最多建造 1 次；建造費為該土地地價的 60%。建造只能在剛落地自己的土地時進行，不能在其他回合預先建造。
- 每塊土地最多可有 4 間房屋。土地已有 4 間房屋時，再次走到該土地即可將 4 間房屋升級為 1 間旅館；房屋與旅館都各佔用 1 次建造機會。
- 房屋租金倍率依序為基礎租金的 3、6、10、15 倍；旅館租金為 22 倍。
- 完整集齊同色地產仍會提供獎勵，但只影響沒有建築的空地：空地租金加倍；不會限制房屋或旅館建造。
- 銀行最多提供 32 間房屋與 12 間旅館。銀行建築用完時，該次無法建造；售出土地或因資金不足自動變賣土地時，建築會回到銀行。
- 包含稅收、機會、城市基金、免費停車與監獄；監獄暫停下一回合。雙骰相同不加擲，無拍賣、抵押或玩家間交易。

付不出費用時由低價地產開始，以原價及建造費合計的 50% 自動變賣；仍無力償還即破產。最後存活玩家獲勝，或 40 輪後以總資產最高者獲勝。同總資產時以玩家順序決勝。

進度自動存到目前瀏覽器的 localStorage，網址及瀏覽器不同則存檔不共用。動畫中的重新整理會回到上一個穩定狀態。新遊戲會取代目前存檔。這是本機單人對電腦遊戲，沒有線上連線模式。
